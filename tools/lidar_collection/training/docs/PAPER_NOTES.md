# 论文方法对照与实现边界

参考：[Hoeller et al., Neural Scene Representation for Locomotion on Structured Terrain](https://arxiv.org/pdf/2206.08077)，III-A/B/C/E。

`sparse4d_v1` 是依据论文描述实现的 4D 稀疏网络。默认 `sparse4d_v3` 是用户指定的持续 GRU 记忆与残差地图更新，不是论文原模型。没有找到作者公开的完整训练源码或预训练权重，所以不能将本目录称作“作者原始代码”或声称逐层逐参数完全一致。它使用真实的 MinkowskiEngine 稀疏算子，不将时间拼成稠密 3D 特征通道。

| 论文要点 | sparse4d_v1 实现 |
|---|---|
| 3.2 m 局部立方体，64³ 网格 | 默认 5 cm 体素、3.2 m 地图 |
| 4D 坐标与 3 维特征 | COO 坐标 `(batch,x,y,z,t)`；体素内点云质心相对左后下角的归一化偏移 |
| 当前观测 t=0、上一帧预测 t=1 | `temporal_input`；历史以世界坐标保存，每帧重新定位和体素化 |
| 4 次空间 stride 2，保留时间维 | 编码器 stride `[2,2,2,1]`，4D 空间时间卷积 |
| 编码—解码与 skip connections | 4 层编码器、4 层生成式转置卷积解码器，跳接 |
| 多尺度占据预测和剪枝 | 每个解码尺度有独立 BCE 分类头；阈值默认 0.5；各层均裁剪到地图范围 |
| 亚体素精度 | 最终 3 维偏移头，目标占据体素上使用平均欧氏误差 |
| 自回归训练，12 步展开 | 默认 12 帧，反馈 detach；序列不跨 reset |
| Adam 0.01 衰减到 0.0001 | 初始学习率 0.01；选 exponential 按总轮数指数衰减，新训练默认 plateau 属于扩展 |
| 输入点噪声 ±5 cm、倾斜 ±1° | `paper` 增强使用均匀点扰动和随机水平轴倾斜 |
| 局部高度噪声、缺失、离群点、位姿噪声 | 两个高度扰动块、一个缺失块、一簇离群点；位置误差各轴 ±5 cm |
| 整段轨迹沿 x/y 镜像 | 每个训练窗口固定镜像方向，同时变换观测、真值与位姿 |

## 论文未明确公开的结构细节

以下选项是本实现的明确选择，不能冒充已核实的作者设置：

- 通道数默认 16、32、64、128、256，可通过 `--base_channels` 整体缩放；使用 sparse BatchNorm 和 ELU。
- 在最粗层查询完整的 `4×4×4×2` 坐标格，为未观测区域提供生成候选；这只分配最粗层的小网格，不把网络改成稠密 3D CNN。
- 使用 `[1,1,1,2]` 的可学习 4D 卷积将两个时间平面合并为 t=0，作用于瓶颈和各层跳接。编码器的时空卷积和跳接已融合两帧信息；解码器只生成当前时间平面的几何。
- 跳接采用坐标并集上的特征相加，不对不同坐标映射直接调用 `ME.cat`。
- 最终偏移使用 sigmoid；四级 BCE 取平均后，与偏移欧氏误差相加。
- 剪枝完全由预测概率决定，训练也不通过真值强制保留正样本。真值只参与 loss，避免标签决定的候选结构进入时序反馈。初始化分类头时保留候选，以避免一开始所有层被剪空；空输入和全部剪空均有明确处理。
- 高度扰动块半径 0.2–0.6 m，缺失块半径 0.15–0.6 m，离群簇为 32 点、标准差 3 cm；论文没有列出这些细节的完整分布。

## 用户指定的持续 GRU 残差结构（v3）

`sparse4d_v3` 使用当前观测和历史预测两来源，`3×3×3×3` 编码跨来源混合，五级 GRU 保存上一时刻的隐藏特征；历史地图和隐藏网格对齐后参与下一帧更新。解码器生成候选并剪枝，最终输出占据/质心残差，没有观测邻域硬限制。默认不额外编码相对位姿，位姿只用于几何对齐。

这是本项目扩展，不是 Transformer、cross-attention 或论文原模型。v1 仍直接预测地图，旧 v1 权重兼容。v2 已移除，已有训练数据和报告保留。

## 用户指定的训练扩展

v3 默认随机选择连续片段的起点、平板初始化：首帧历史地图是固定水平平板，另一路是当前观测，隐藏状态为零；之后反馈实际预测和隐藏特征。训练、验证和部署都不用 GT 初始化。训练默认每 4 帧截断隐藏特征梯度但保留其值。v1 保留旧 `previous_gt` 训练配方，也可选择 `empty` 避免初始化使用真值；验证始终不用 GT 初始化。两版均按时间连续递归，不跨 reset。

噪声幅度、体素丢弃和质心抖动可调，监督标签保持干净；示例使用 ±2 cm 点噪声，与论文的 ±5 cm 不同。

新建 sparse4d 训练还默认使用按验证损失触发的 ReduceLROnPlateau 自适应衰减；它不属于已核实的论文指数衰减配置。用 `--lr_scheduler exponential` 可恢复原衰减模式。

## 当前机器人与数据适配

坐标约定需要区分论文与实现：论文图 2、III 节明确写上一帧预测按两帧位姿差变换到当前测量坐标系；这不等于声明采用固定世界坐标轴。下面的世界轴保持方案是本项目 v1/v3 的具体适配选择。新增 v3 的历史地图和隐藏特征保持世界轴、按中心位移重定位，持续 GRU 状态、TBPTT 与无邻域限制的残差输出都是用户指定扩展，详见 [v3 说明](RECURRENT_V3.md)。

当前使用雷达点，不是论文的四个深度相机。地图轴保持世界方向、中心跟随机器人，与已有世界轴对齐真值区域一致。传感器旋转已包含在世界坐标点中，因此历史地图重定位只需要中心位移；四元数不再额外拼入 sparse4d 的网络特征。地形、轨迹数量、数据增强细节和训练批次与论文不完全相同。

3D 基线保留旧的 12 通道输入、3 次降采样和加权 BCE。默认使用旧的 basic 增强与学习率，不是只替换卷积维度的严格控制变量消融。两者可共用同一数据划分和评估指标；比较时请记录各自配置，必要时显式统一 `--augmentation`、学习率和训练预算。
